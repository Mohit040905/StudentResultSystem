# 🎓 Student Result Management System

A production-style **REST API** built with **Spring Boot, JPA/Hibernate, and MySQL** to manage student academic results. Supports full CRUD operations for students, subjects, and results with auto-calculated grades and percentage.

---

## 🛠️ Tech Stack

| Layer         | Technology                        |
|---------------|-----------------------------------|
| Language      | Java 17                           |
| Framework     | Spring Boot 3.2                   |
| ORM           | JPA / Hibernate                   |
| Database      | MySQL 8                           |
| Build Tool    | Maven                             |
| API Testing   | Postman                           |
| Validation    | Spring Boot Validation (JSR-303)  |

---

## ⚙️ Setup Instructions

### 1. Clone the Repository
```bash
git clone https://github.com/Mohit040905/StudentResultSystem.git
cd StudentResultSystem
```

### 2. Configure Database
Edit `src/main/resources/application.properties`:
```properties
spring.datasource.password=your_mysql_password
```
> The database `student_result_db` is auto-created on first run. Tables are auto-generated by Hibernate.

### 3. Build & Run
```bash
mvn clean install
mvn spring-boot:run
```

The API starts at: **http://localhost:8080**

## 📮 API Endpoints

### 👨‍🎓 Students — `/api/students`

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST   | `/api/students` | Add new student |
| GET    | `/api/students` | Get all students |
| GET    | `/api/students/{id}` | Get student by ID |
| GET    | `/api/students/roll/{rollNumber}` | Get by roll number |
| GET    | `/api/students/department/{dept}` | Get by department |
| GET    | `/api/students/department/{dept}/semester/{sem}` | Get by dept + semester |
| PUT    | `/api/students/{id}` | Update student |
| DELETE | `/api/students/{id}` | Delete student |

**POST /api/students — Request Body:**
```json
{
  "firstName": "Mohit",
  "lastName": "Morande",
  "email": "mohit@example.com",
  "rollNumber": "IT2023001",
  "department": "Information Technology",
  "semester": 5
}
```

---

### 📚 Subjects — `/api/subjects`

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST   | `/api/subjects` | Add new subject |
| GET    | `/api/subjects` | Get all subjects |
| GET    | `/api/subjects/{id}` | Get subject by ID |
| GET    | `/api/subjects/semester/{sem}` | Get by semester |
| PUT    | `/api/subjects/{id}` | Update subject |
| DELETE | `/api/subjects/{id}` | Delete subject |

**POST /api/subjects — Request Body:**
```json
{
  "name": "Data Structures and Algorithms",
  "subjectCode": "IT301",
  "maxMarks": 100,
  "semester": 3,
  "department": "Information Technology"
}
```

---

### 📊 Results — `/api/results`

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST   | `/api/results` | Add result (grade auto-calculated) |
| GET    | `/api/results/student/{id}` | All results for a student |
| GET    | `/api/results/student/{id}/semester/{sem}` | Results by semester |
| GET    | `/api/results/student/{id}/average` | Overall average percentage |
| PUT    | `/api/results/{resultId}?marks=85` | Update marks |
| DELETE | `/api/results/{resultId}` | Delete result |

**POST /api/results — Request Body:**
```json
{
  "studentId": 1,
  "subjectId": 1,
  "marksObtained": 87
}
```

**Sample Response:**
```json
{
  "success": true,
  "message": "Result added successfully",
  "data": {
    "studentName": "Mohit Morande",
    "rollNumber": "IT2023001",
    "subjectName": "Data Structures and Algorithms",
    "marksObtained": 87,
    "maxMarks": 100,
    "percentage": 87.0,
    "grade": "A+",
    "remarks": "Excellent"
  },
  "timestamp": "2026-01-15T10:30:00"
}
```

## 🎯 Grading System

| Percentage | Grade | Remarks     |
|------------|-------|-------------|
| ≥ 90%      | O     | Outstanding |
| ≥ 80%      | A+    | Excellent   |
| ≥ 70%      | A     | Very Good   |
| ≥ 60%      | B+    | Good        |
| ≥ 50%      | B     | Average     |
| ≥ 40%      | C     | Pass        |
| < 40%      | F     | Fail        |

## ✨ Key Features

- Full CRUD for Students, Subjects, and Results
- **Auto grade & percentage calculation** using `@PrePersist` / `@PreUpdate`
- **Input validation** with descriptive error messages
- **Global exception handling** — clean JSON errors, no HTML pages
- **Duplicate prevention** — unique email, roll number, and student-subject result
- **Standard API response** — every endpoint returns consistent JSON structure
- JPA relationships: `@OneToMany`, `@ManyToOne` with foreign keys
